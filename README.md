# BEQSON Digital Studio

Готовый статический сайт для GitHub Pages.

## Что внутри
- `index.html` — главная страница
- `styles.css` — стили
- `script.js` — контакты и небольшая логика
- `assets/` — SVG-иллюстрации и логотип
- `robots.txt`
- `sitemap.xml`
- `site.webmanifest`
- `EDIT-CHECKLIST.md` — что поменять перед запуском

## Как загрузить в GitHub
1. Открой репозиторий `digital-office-studio`.
2. Нажми **Add file → Upload files**.
3. Залей **все файлы и папки** из этой папки в корень репозитория.
4. Commit changes.
5. Открой **Settings → Pages**.
6. В Source выбери **Deploy from a branch**.
7. Branch: **main**, Folder: **/(root)**.
8. Сохрани и подожди 1–5 минут.
9. Сайт откроется по адресу вида:
   `https://bequcho.github.io/digital-office-studio/`

## Что важно поменять
- Контакты в `script.js`
- Почту / Telegram / WhatsApp
- Домен в `sitemap.xml` и `site.webmanifest`, если будет свой домен
- Тексты цен и пакетов при необходимости

## Если появился 404
- проверь, что Pages включён на `main` и `/(root)`
- подожди 2–5 минут после коммита
- убедись, что `index.html` лежит именно в корне репозитория
