# Быстрая настройка перед запуском

## 1) Контакты
Контакты уже заполнены. Если когда-нибудь изменятся, открой `script.js` и поменяй:
- `phoneDisplay`
- `phoneLink`
- `whatsappNumber`
- `telegramDisplay`
- `telegramLink`
- `email`

## 2) Домен
Если оставляешь GitHub Pages URL — можешь ничего не менять.
Если подключишь свой домен:
- замени URL в `sitemap.xml`
- замени URL в `site.webmanifest`

## 3) Контент
При желании поменяй:
- цены в `index.html`
- описание услуг
- список направлений
- блок FAQ
- заголовок и мета-описание

## 4) Запуск
Загрузи всё в корень репозитория и включи GitHub Pages:
`Settings → Pages → Deploy from a branch → main → /(root)`
